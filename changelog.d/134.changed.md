Resumable run streams now cap retained history by event count and encoded frame bytes; a join with an evicted `Last-Event-ID` returns `409`. Stateless `/runs/stream` never retains history because its run cannot be joined later.

Finished resumable history is also bounded per worker by `resumable_stream_max_retained_runs` (default 16); oldest finished buffers are evicted first, and their joins return final-state events instead of replay.

Closing a subscriber queue at exact capacity preserves all buffered events, including the terminal event; overflow is reported only when publication exceeds capacity.
