Runs left `pending`/`running` by a process that died without a graceful shutdown (crash, OOM kill, hard restart) no longer stay in flight forever. Each process heartbeats the runs it executes (`SkeinoSettings.run_heartbeat_seconds`, default 30). A sweep at startup and on every tick marks in-flight runs whose heartbeat is older than `orphaned_run_timeout_seconds` (default 120; `None` disables) as `error` with an "orphaned" reason, and moves their thread off `busy`. It is safe across workers sharing a database: a process never sweeps its own runs, and each row is claimed atomically. Adds `touch_runs` / `fail_stale_runs` to `MetadataStoreProtocol`, so custom metadata stores must implement them.
